# Uncrowned — what v1 is

> **Dated 2026-09-13, morning.** This records what v1 **delivered**. v2 was specified and
> built the same day and changed several things below — the beasts are gone, hardship
> and the four places' states exist, rank reads standing, the opening points two ways —
> so read `V2.md` for what the game is now, and this for what it was built on.

> **Read this first.** `SPECS.md` is three thousand lines and answers *what the game
> should be*; this answers *what it currently is*, which is the question you have if
> you have just arrived. Delivered 2026-09-13.

An open-world RPG about holding a king to account. The player wakes in a clearing with
no memory, raised by fairies who are dying because the king is clearing the forest for
charcoal. They can walk from that clearing to the castle in minutes and attack the
king, and will lose. **Progress comes from power, knowledge and social access — never
from a flag**, which is the pillar everything below is arranged to protect.

The game is written and played in **French first** and translated into English.

---

## Run it

```bash
godot --headless --path . --import          # once after cloning
tools/run_tests.sh                          # fast suite, ~4.7 s
tools/run_tests.sh --all                    # everything, ~18 s — before committing
godot --path . &                            # play it
tools/shot.sh /tmp/a.png play 150,174       # look at one frame without playing
```

`tools/shot.sh out.png [title|creation|play|pause|journal|map] [x,y]` is not a
convenience. `--headless` never calls `_draw()`, so **the suite cannot see the screen
at all** — every visual bug this project shipped was invisible to 371 tests and
obvious in a picture.

## The one rule everything else protects

`core/` never imports from `view/`. `view/` reads `core/` and never writes to it.
Input becomes an *event*; the simulation advances only through `Sim.advance()`.

Three things fall out of that, and they are the reason to keep it:

- **A save is its event log and nothing else.** Loading is replaying. There is no
  snapshot that can drift out of step with the world, and `Game.replay()` is exercised
  by tests that have run since Phase 0 — so loading a save is not a feature with its
  own bugs.
- **The rendering layer is replaceable.** `Art` and `Sound` are tables from things the
  simulation already says to files in the pack; `core/` does not know a furnace has a
  sprite or that Saltmarch sounds like water.
- **Determinism.** One seed, one world. `sim.rng`, never global `randf()`.

## What is built

| | Where | |
|---|---|---|
| **The world** | `core/region.gd` | One 280 × 200 region. Eight places are *areas of it*, not separate scenes: Brindle, the Cinderworks, Harrowgate, the Wide Acres, the Muster, Saltmarch, Cairnwell, Blackcairn — plus the fairies' clearing, which is not a zone. The Thornwood is closed wood with ways carved through it; Blackcairn is a wall with a gate |
| **The opening** | `core/rules/opening_rules.gd` | You wake in the clearing, the fairy tells you seven things and is forbidden the rest, and then she is gone. A conversation, not a cutscene |
| **People** | `content/cast.*.json`, `core/cast.gd` | Twenty-five with names and sheets, one of whom is the fairy and is drawn as light rather than sprited. Everyone else has a face nobody else uses, and a test enforces it |
| **Dialogue** | `core/rules/dialogue_rules.gd` | Authored, deterministic. Options are gated by facts, standing, conditions and traits; a reaction opener is said once per conversation |
| **The fact base** | `core/fact_base.gd` | What the player knows. Every fact has more than one source (invariant 6), which is what makes killing people survivable |
| **Quests** | `core/rules/quest_rules.gd` | Eight, and each is a *predicate over the fact base* — no store, no system, no migration. Nothing opens a quest but learning something |
| **Character creation** | `core/traits.gd`, `core/rules/trait_rules.gd` | Six traits, a pool of ten, a cap of five, chosen once and never raised. One external event carrying six numbers, so it lives in the save |
| **Standing & rumour** | `core/standing.gd`, `core/rumours.gd` | Per town and per person. A rumour arrives days after the act that caused it |
| **Factions** | `core/rules/faction_rules.gd` | Two sides, four ranks each, read off service rather than stored. Service comes from the deed table, so every act already in the game counts |
| **The world's clock** | `core/world_tick.gd` | Twelve tracked quantities drifting on their own. One tick is one in-game minute; the overworld runs four a second |
| **Endings** | `core/rules/end_rules.gd` | Five: `dead`, `ruined`, `deposed`, `discredited`, `abandoned`. **A predicate over the tracked quantities, never a completed route** — and each needs a minimum *handprint*, so drift can never end the game |
| **Saving** | `core/save_file.gd` | Rest at a campfire. Dying puts you back at the last one |
| **The screens** | `view/screens.gd` | Title, character creation, the world, pause. Each emits `chose(what, carrying)` and knows nothing about the others |
| **The journal** | `view/main.gd` | Six pages on `J`. §8's NARRATED register — the only screen allowed to join an act to its consequence, and it is *pulled*, never pushed |
| **Audio** | `view/sound.gd` | Music by place, ambience by ground, cues by what happened. Switchable off |
| **Two languages** | `content/text.*.json`, `view/text.gd` | French and English. A test refuses to let either fall behind |

**Twenty-one systems** in `core/systems/`, all stateless and rebuilt on replay.
**Thirty-five suites, 371 tests** — `tools/run_tests.sh --all`.

## What is deliberately switched off

**There is no LLM in v1**, decided 2026-09-12 and measured rather than argued. The
machinery is all still here and all still tested: `core/context.gd` (the packet),
`core/rules/prose_rules.gd` (the door), `core/phrasebook.gd`, `PhrasingSystem`,
`view/phraser.gd`, `tools/phrase.py`. `Phraser.phrase()` returns `""` and nothing asks
it anything.

**Before reopening it, read the reason.** The failure was not that the models wrote
badly — it was that *nothing automatic catches a sentence meaning the opposite of what
it was given*. The door checks figures, names, register and formatting, the pass rate
went **up to 94%**, and the meaning went backwards five times in six. A better model
produces better prose with the same unverifiable failure, which is the worse state
because it looks fine. The experiment that reopens this is **"can an inverted line be
caught automatically"**, not "is this model better at writing". See CLAUDE.md and
`SPECS.md` §9.

**Nothing in the game is solid via props.** Every prop carries `"solid": false` and
`Region.is_passable` consults terrain and never the prop list — buildings block
because `_place` stamps their footprint as `WALL`, which is a different mechanism.
The flag is dead weight, left in place rather than removed because making props solid
can trap a player and wants its own test before anyone tries it.

## What v1 does not have

Stated plainly, because the gaps are the interesting part of a handover.

- **Combat.** Phase 4 is out of v1 by decision. The king still kills the player *on
  contact in the overworld, three touches* — the last standing exception from Phase 0,
  and now the oldest debt in the project. Four of the five endings need no fighting;
  the fifth, killing him, is the one that waits.
- **Two of Blackcairn's three ways in.** §4 promises the gate, a culvert and a cliff
  path. Only the gate exists, so the gate stands open — a castle nobody can enter
  would close every route at once.
- **Interiors.** The keep's inside is a zone for a later phase. The portal machinery
  (`ZoneSystem`) exists and is tested; nothing uses it yet.
- **An exportable build.** There is no `export_presets.cfg`, so there is nothing to
  hand to anyone who does not have Godot.
- **CI.** The suite is run by hand.
- **An options screen.** §16. Language and sound are rows on the title and pause
  menus, kept in `user://settings.cfg`; there is nothing else to set.
- **A README.** This file is the nearest thing.
- **Anonymity for the crowd.** Townsfolk share sheets with named people who stand in
  other towns. Deliberate — §6 keeps them out of the cast so they cannot acquire a
  name — but it is a compromise, not a solution.

## The four development tools, all gated on `OS.has_feature("debug")`

`T` skips an in-game day · `M` opens the map of Erileo · the journal's last page lists
who is where · `tools/shot.sh` photographs any screen. They are absent from a release
export. **Anything else of this kind goes behind the same gate and gets written into
CLAUDE.md** — a debug tool nobody recorded is a debug tool that ships.
