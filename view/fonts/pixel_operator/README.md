# Pixel Operator

The game's one typeface since D1 (2026-10-09). By Jayvee Enaguas (HarvettFox96),
released under **CC0 1.0** — the licence is `LICENSE.txt`, beside it.

Downloaded from dafont (`pixel_operator`) on 2026-10-09; the files here are the 16-pixel
cuts, regular and bold, unedited. The 8-pixel cut of the same family was tried and
refused: its accented capitals stand no taller than an *E*, so *Écouter* read *écouter*.

Drawn sharp at sizes that are multiples of eight (`Ui.FONT_GRID`): the window doubles the
640×360 canvas, so eight is one pixel of the font to one of the screen. Imported with no
antialiasing, no hinting and no subpixel positioning, for the same reason.
