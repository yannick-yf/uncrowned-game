# Farming village kit

54 native Godot prefabs, in metres, with shared procedural materials and compressed
indexed meshes. Open `../../scenes/catalogue_fermier.tscn` in the workshop to inspect
them. See [placement, reconstruction and validation guide](../../planning/Village-fermier-assets.md).

`catalog.json` is the generated inventory, including scene paths, dimensions,
placement notes, per-piece geometry counts and provenance. Model geometry is original
work for Uncrowned; no external model/texture pack was downloaded for this kit.
